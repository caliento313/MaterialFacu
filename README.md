# 📚 Trabalhos Realizados da Faculdade de Análise e Desenvolvimento de Sistemas

Este repositório reúne os principais **trabalhos acadêmicos desenvolvidos durante o curso de Análise e Desenvolvimento de Sistemas (ADS)**.  
Os projetos aqui apresentados refletem a aplicação prática dos conhecimentos adquiridos ao longo da graduação, abrangendo áreas como **programação, banco de dados, análise de sistemas, lógica computacional e desenvolvimento de software**.

O objetivo deste repositório é documentar a evolução acadêmica, demonstrar competências técnicas e servir como **portfólio de estudos**, evidenciando a capacidade de resolver problemas, desenvolver soluções computacionais e trabalhar com diferentes tecnologias.

---

## 🎯 Objetivo do Repositório

- Centralizar os trabalhos desenvolvidos ao longo do curso de ADS  
- Aplicar conceitos teóricos em projetos práticos  
- Demonstrar habilidades técnicas e evolução profissional  
- Servir como base de estudo e consulta futura  
- Apoiar a construção de um portfólio na área de Tecnologia da Informação  

---

## 🧠 Conhecimentos Aplicados

Durante o desenvolvimento dos trabalhos, foram aplicados conhecimentos nas seguintes áreas:

- **Lógica de Programação**
- **Programação Estruturada e Orientada a Objetos**
- **Análise e Modelagem de Sistemas**
- **Banco de Dados Relacionais**
- **Algoritmos e Estruturas de Dados**
- **Engenharia de Software**
- **Desenvolvimento Web e Desktop**
- **Automação de Processos**
- **Versionamento de Código com Git e GitHub**
